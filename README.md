# flowsim v2 — Pedestrian Flow Lab

Plaza and massing design with a live pedestrian simulation, in one HTML file.
Draw masses, split them, push and pull faces, place cores, design the ground
(paths, paving, planting, water, furniture), lay out every floor (walls, doors,
rooms, areas), paint materials face by face, and watch people move through it.

The successor of Street Flow Lab (`street-flow-lab`): Snaptrude-style drawing,
smart guides, three design tabs (Mass · Site & plaza · Interior), architectural
drawing standards for plan, section and elevation, and a vertical materials and
furniture bar.

## Run it

Open `index.html` in a browser. Nothing to install; three.js r128 is loaded from a CDN.

## Build

`index.html` is generated from `app.html`, `engine.js` and `site-vancouver.js`:

```
node build.mjs
```

The Vancouver competition site (`site-vancouver.js`) is generated by
`tools/gen_site.py` from the tower base model's `site.json`.

## Tests

Headless Playwright suites, one per feature (`*_test.mjs`). Each one drives the
app through `window.PFL_APP` and prints `N pass, M fail`:

```
node tools_test.mjs ./shots/
```

They expect a Playwright install (see the import path at the top of each file)
and a Chromium with software WebGL.

## Layout

- `app.html` — the app: views, tools, panels, drawing, undo, tests hook
- `engine.js` — site and interior models, simulation, metrics
- `site-vancouver.js` — the Vancouver Tall site model
- `build.mjs` — inlines the scripts into `index.html`
- `*_test.mjs` — the scripted checks
- `tools/` — site generator
